# Appels CIUSSS : guides de prise de RDV

Application d'aide aux appels téléphoniques (prise de rendez-vous) construite à partir des protocoles du CIUSSS du Centre-Ouest-de-l'Île-de-Montréal : rougeole, maladies chroniques, dcaT, Strep A, vaccination enfants et adultes, TCT, campagne grippe/COVID/VRS, trajectoire pédiatrique, dépistage COVID, cancer colorectal, VPH, VRS bébés, prélèvements et zona.

Un seul fichier : ouvrez `index.html` dans un navigateur. Chaque chapitre se joue en 3D (plateaux, serpents et échelles, stand de tir) ou en vue classique.

Les numéros internes réservés au personnel (« Ne pas donner aux usagers ») sont retirés de cette version publique.
